# Whisper-Live-Subtitle
ANDROID APP that can RECOGNIZE ANY LIVE AUDIO/VIDEO STREAMING (using Tiny Whisper Model tiny-decoder.int8.onnx and tiny-encoder.int8.onnx from Sherpa ) then TRANSLATE (using unofficial online Google Translate API) and display it as LIVE CAPTION / LIVE SUBTITLE
